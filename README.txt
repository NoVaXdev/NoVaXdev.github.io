WHATSAPP
The floating WhatsApp control is intentionally small. Click the WhatsApp icon, type a message, and press Send. If the cart has items, Use cart inserts the order list into the message.

IMPORTANT FOR LIVE DEPLOYMENT
This project is a static front-end demo and keeps demo authentication logic in JavaScript. For a real live portal, move authentication and credentials to a server-side backend and database. Hiding the public portal link alone is not a security boundary.
CURRENT GALLERY AND WHATSAPP
